# RasyoTrend Blog Arayüzü

Bu repository, RasyoTrend Blogger ana tema ve özel sayfa frontend kodlarını yönetir. Canlı ana tema baz dosyası `tema/rasyotrend-tema.xml` yolundadır.

Tema değişiklikleri bir branch üzerinde hazırlanır; Pull Request ve kullanıcı kontrolü tamamlandıktan sonra Blogger'a uygulanır.

Finansal veri üretimi bu repository'nin görevi değildir. Public JSON verileri ileride frontend tarafından yalnızca okunacak; finansal hesaplamalar frontend içinde yeniden yapılmayacaktır.
