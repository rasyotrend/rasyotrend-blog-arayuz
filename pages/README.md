# Statik yayın dizini

Bu dizin GitHub Pages'e verilecek yayın ağacının kaynağıdır. Beklenen public URL yapısını korumak için, Actions kullanılmadan `pages/` içeriğinin köküne alındığı ayrı bir yayın branch'i (`gh-pages`) ve Pages kaynağı olarak o branch'in `/(root)` seçimi önerilir. Repository içindeki kaynaklar `ortak/`, `ana-tema/` ve `sayfalar/` dizinleridir; Pages ayarı bu çalışma tarafından etkinleştirilmez.
