# Ana tema modülleri

Bu dizindeki CSS ve JavaScript dosyaları **production-ready replacement değildir**. Modülerleşme için geçiş iskeleti ve sorumluluk sınırı oluştururlar.

Çalışan production kaynağı `tema/rasyotrend-tema.xml` içindeki `b:skin` ve inline JavaScript'tir. Özellikle `js/navigasyon.js`, `js/slider.js` ve `js/kategori-siralama.js`, XML'deki bütün davranışın tam işlevsel eşdeğeri değildir. Blogger Preview üzerinde görünüm ve davranış eşdeğerliği doğrulanmadan XML içindeki kodun yerine kullanılmayacaktır.
