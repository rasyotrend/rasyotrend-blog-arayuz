# Statik yayın dizini

GitHub Pages `Settings → Pages` altında `Source: Deploy from a branch`, `Branch: main`, `Folder: /docs` ayarlarıyla yapılacak yayın için hazırlanacak sürümlü, dağıtılabilir asset kopyaları burada yer alır. Kaynak kodun asıl yeri `ortak/`, `ana-tema/` ve `sayfalar/` dizinleridir. GitHub Actions kullanılmaz.
