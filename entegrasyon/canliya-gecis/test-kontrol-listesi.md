# Canlı pilot test kontrol listesi

- [ ] Pages origin ve tüm v1.0.0 assetleri HTTPS 200 dönüyor.
- [ ] CSS, JavaScript ve JSON MIME başlıkları doğru.
- [ ] Cache başlıkları ile immutable sürüm politikası uyumlu.
- [ ] Blogger preview'da loading, içerik ve hata fallback'i okunabilir.
- [ ] CORS yalnız izinli originlerde çalışıyor.
- [ ] 404, ağ kesintisi ve timeout senaryoları görünür fallback veriyor.
- [ ] Null “Veri yok”, boş dizi boş durum; hiçbir değer 0'a çevrilmiyor.
- [ ] Duplicate snippet ikinci yüklemeyi başlatmıyor.
- [ ] 320, 360, 375, 390, 430, 768 ve 1024 px kontrol edildi.
- [ ] Klavye, odak, Escape (uygulanabilir bileşenlerde) ve aria-live kontrol edildi.
- [ ] Console'da hata ve mixed-content uyarısı yok.
- [ ] Rollback adımları ve önceki immutable sürüm URL'si hazır.
