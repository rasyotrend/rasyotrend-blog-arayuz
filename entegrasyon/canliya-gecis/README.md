# Canlıya geçiş paketi

Bu paket **otomatik deploy yapmaz**. Sıra: (1) rapor/diff onayı, (2) GitHub Pages ayarı, (3) public pilot smoke testi, (4) Blogger Preview'a `blogger-pilot-loader.html` yapıştırma, (5) kontrol listesini tamamlama, (6) kullanıcı onayıyla pilot yayın. Ana tema XML'i bu pilotun parçası değildir.
