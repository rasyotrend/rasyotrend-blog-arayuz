# Canlıya geçiş paketi

Bu paket production'a otomatik yayın yapmaz. Sıra: PR inceleme/merge kararı, Pages'i manuel etkinleştirme, URL/MIME/cache kontrolleri, Blogger preview'a `blogger-pilot-loader.html` uygulama, kontrol listesini yürütme, sonra sınırlı pilot yayını. Pilot JSON test verisidir; gerçek public JSON bağlı değildir. Tema XML bu paketin dışında kalır.
