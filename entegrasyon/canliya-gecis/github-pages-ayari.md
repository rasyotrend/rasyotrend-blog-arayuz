# GitHub Pages ayarı (manuel)

1. GitHub'da repository **Settings → Pages** sayfasını açın.
2. **Build and deployment / Source** için “Deploy from a branch” seçin.
3. Entegrasyon değişiklikleri onaylanıp `main`e merge edildikten sonra branch olarak `main`, klasör olarak `/pages` seçeneği sunuluyorsa onu seçin. GitHub arayüzü yalnız `/ (root)` veya `/docs` sunuyorsa yayın yapısını taşımadan önce repository yöneticisiyle stratejiyi doğrulayın; bu pakette Actions eklenmemiştir.
4. Kaydedin ve GitHub'ın verdiği yayın URL'sini bekleyin.
5. `https://rasyotrend.github.io/rasyotrend-blog-arayuz/` ve `/assets/v1.0.0/` altındaki dosyaları kontrol edin.
6. Production kontrol matrisindeki gerçek HTTP/MIME/CORS/cache testlerini tamamlamadan Blogger'a geçmeyin.

Bu çalışma ayarı değiştirmemiş ve Pages'i etkinleştirmemiştir.
